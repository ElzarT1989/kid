# CLAUDE.md — контекст и правила для Claude Code

Полная архитектурная спецификация — в `SPEC.md`. Этот файл — рабочий
контекст и правила генерации кода для последующих сессий.

## Кто и зачем

Пользователь — родитель троих детей (2 года, 5 лет, 6 месяцев), у него
два выделенных смартфона Samsung Galaxy S20+. Проблема: обычное
образовательное видео на YouTube/VK через 15–20 минут алгоритм
рекомендаций утаскивает в треш (распаковки, шортсы, нейрослоп). KidsEdu
AI — система изоляции детей в киоск-режиме с заранее одобренным
образовательным плейлистом.

Этот проект **отделён по инструментам и лимитам** от медицинского
проекта пользователя (репозиторий `Medical_backend`, Railway-проект
`industrious-beauty`) — не смешивать, не трогать чужой контекст.

## Текущий статус (см. SPEC.md, раздел 7)

**Этап 1 (Инфраструктура и ядро БД) — реализован.** Backend-скелет в
`backend/`: 8 таблиц БД, admin/player API, рабочий Telegram-бот
(`/status`, `/add_channel`, `/list_channels`, `/block_video`), заглушки
сервисов Этапов 2–4.

**Этапы 0, 2, 3, 4, 5 — не начаты.** Следующий приоритет — Этап 0
(физическая изоляция: Fully Kiosk Browser + минимальный статический
плейлист) параллельно с Этапом 2 (ingestor + moderator + tts).

## Правила генерации кода

1. Backend: Python 3.11, FastAPI, SQLAlchemy 2.0 AsyncIO, Pydantic v2.
2. Все новые модели БД — в `backend/app/models/database.py`, с
   `Mapped[...]`/`mapped_column`, без legacy `Column`.
3. Pydantic-схемы для LLM/API — в `backend/app/schemas/`, не смешивать с
   ORM-моделями.
4. Секреты (`TELEGRAM_BOT_TOKEN`, `GEMINI_API_KEY`, ключи Railway) —
   только через переменные окружения (`.env`, Railway variables),
   никогда не хардкодить и не логировать.
5. Видео скачивается локально после одобрения модератором
   (`VideoItem.local_video_path`) — не кэшировать "живые" HLS/MP4 ссылки
   (см. `SPEC.md`, п. 8.1).
6. Двухслойная модерация обязательна перед `is_approved=True`: текстовый
   слой (субтитры → Gemini) и визуальный слой (ffmpeg + Gemini vision) —
   см. `SPEC.md`, п. 8.5. Не считать модерацию по субтитрам достаточной.
7. Монетизация и работа с видео других детей — вне скоупа, не
   предлагать и не реализовывать без явного запроса пользователя (юр.
   вес: 152-ФЗ, права на видео).
